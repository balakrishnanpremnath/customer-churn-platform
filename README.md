# Customer Churn Intelligence Platform

An end-to-end Data Science and Machine Learning project focused on predicting customer churn, interpreting model decisions, and supporting data-driven customer retention strategies.

> **Project status:** In development. Features described below are planned, not yet implemented.

## Project Objectives

- Explore customer behavior and churn patterns.
- Build reproducible data preprocessing pipelines.
- Compare baseline and advanced classification models.
- Evaluate models using appropriate research metrics.
- Explain predictions using SHAP.
- Develop an interactive analytics dashboard and prediction API.
- Document testing, deployment, and research findings.

## Planned Technology Stack

| Component | Technology |

## Getting Started (Windows CMD)

```cmd

 cd customer-churn-platform
 py -3.12 -m venv .venv
 .venv\Scripts\activate.bat
```

Additional installation and execution instructions will be added as development progresses.

## Research Approach

The research plan includes leakage prevention, held-out evaluation, suitable cross-validation, model comparison, classification metrics, probability calibration, and clearly documented limitations.
